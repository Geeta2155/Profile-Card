# Profile Card

A beautiful and responsive profile card website showcasing personal information and social links.

Can Visit by clicking on the link:- https://geeta2155.github.io/Profile-Card/

## Features

- Responsive design that works on all devices
- Clean and modern UI
- Social media links with icons
- Profile image display
- Interactive elements
- Smooth animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
Profile-Card/
├── index.html          # Main HTML file
├── style.css           # Stylesheet
├── script.js           # JavaScript functionality
└── Geetanjali Umap.jpg # Profile image
```

## Customization

To customize this profile card for your own use:

1. Replace `Geetanjali Umap.jpg` with your own profile picture
2. Update the personal information in `index.html`
3. Modify the social links in `index.html`
4. Adjust the styling in `style.css` to match your preferences
